Usage Examples

JavaScript API

// Enable scrolling for a specific tab TabScrollingController.enableScrolling('general-info'); // Disable scrolling for a specific tab TabScrollingController.disableScrolling('generate-metadata'); // Toggle scrolling for a specific tab TabScrollingController.toggleScrolling('traits-rules'); // Set configuration for multiple tabs TabScrollingController.setScrollingConfig({ 'general-info': true, 'traits-rules': false, 'generate-nfts': true, 'generate-metadata': false, 'export-nfts': false }); // Get current configuration const config = TabScrollingController.getScrollingConfig(); // Reset to defaults TabScrollingController.resetToDefaults();

CSS Classes

/* Add to HTML for explicit control */ <div id="general-info" class="tab-content scroll-enabled"> <div id="generate-metadata" class="tab-content scroll-disabled">
